Ask about this work ↗

THE PROBLEM

What needed solving.

Financial questions require reasoning across narrative text, table cells and chart images, with answers expressed in the shared task’s domain-specific language.

THE APPROACH

How the pieces connect.

A warm-up on rule-converted FinQA and TAT-QA programs precedes adaptation to the task data. The submitted system averages four adapters and uses greedy decoding with fixed post-processing.

IMPLEMENTATION

What the repository contains.

The repository contains data loading and DSL handling, LoRA training and inference, adapter averaging, local metric reconstruction and competition submission packaging. The source-grouped split and external-data manifests are tracked alongside experiment records.

OUTCOME

What came out of it.

The repository reports 69.72% public and 72.46% private Program Accuracy, ranking 4th and 6th respectively.

CONTEXT & LIMITATIONS

Scores and rankings are reported in the project repository; they have not been independently checked against the official leaderboard here. Code is currently private.
