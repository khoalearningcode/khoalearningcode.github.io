ABOUT THE CHALLENGE

VLSP 2026 · ViTNumChart.

A shared task of the Vietnamese Language and Speech Processing workshop on numerical reasoning over Vietnamese financial documents. Each question refers to text, tables and chart images, and the answer is a short program in the task’s own language that can be executed and checked.

ORGANIZERVLSP 2026 shared task
TASKAnswer financial questions by writing a program over text, tables and chart images
DATA1,379 training questions on Vietnamese financial documents; public and private test sets
METRICProgram Accuracy: the generated program must match the reference, argument strings included
RULESThe only model used is an 8B model; external data is disclosed in the project repository
MY RESULT4th on the public test, 6th on the private test
