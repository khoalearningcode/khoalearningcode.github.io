Multi-frame recognition of extremely low-resolution license plates.

PyTorch · SVTRv2 · OCR · Ensemble learning

ABOUT THE CHALLENGE

ICPR 2026 · LRLPR-26.

An international competition on reading license plates from extremely low-resolution video. Each sample is a track: five consecutive crops of one plate, around 49 × 18 pixels, and the system must predict the full plate string and a confidence.

ORGANIZERRayson Laroca et al. · ICPR 2026
TASKRead a 7-character Brazilian or Mercosur plate from five frames
DATA20,000 training tracks and 3,000 test tracks from one surveillance camera in Curitiba, Brazil
METRICRecognition Rate: exact match of the plate string; ties broken by Confidence Gap
PROTOCOLAbout a month of public phase, then a one-week blind phase with at most three submissions per team
PARTICIPATION269 teams registered from 41 countries; 99 took part in the blind phase

Ask about this work ↗

THE PROBLEM

What needed solving.

A single frame can lose the character detail needed to read a plate. The task uses five frames of the same plate, each around 49 × 18 pixels.

THE APPROACH

How the pieces connect.

A shared SVTRv2 encoder creates tokens for each frame. Concatenated memory supports autoregressive decoding, followed by step-synchronous ensemble fusion.

IMPLEMENTATION

What the repository contains.

The code implements the shared SVTRv2 encoder, learned frame embeddings, concatenated-memory autoregressive decoder and step-synchronous ensemble. Configuration files record model members, pretrained initialization and the fixed evaluation protocol.

OUTCOME

What came out of it.

The repository reports 82.03% exact recognition on the released test set of 3,000 tracks, from one preregistered run opened once. Validation predicted it closely (82.00 → 82.03).

CONTEXT & LIMITATIONS

This is a post-competition experiment, not an official competition placement. Scorer and label equivalence could not be fully verified. Small gaps to leaderboard systems fall within sampling noise. Code is currently private.
