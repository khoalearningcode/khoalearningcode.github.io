03 / COMPUTER VISION · LRLPR-26 · Post-competition

Five frames. One clear answer.

Multi-frame recognition of extremely low-resolution license plates.

PyTorch · SVTRv2 · OCR · Ensemble learning
5 low-resolution framesShared encoderPlate sequence

Conceptual illustration of the approach.

AT A GLANCE

82.03% recognition

The project fuses evidence from five low-resolution frames before each character decision, rather than voting only after recognition.

Ask about this work ↗

THE PROBLEM

What needed solving.

A single frame can lose the character detail needed to read a plate. The task uses five frames of the same plate, each around 49 × 18 pixels.

THE APPROACH

How the pieces connect.

A shared SVTRv2 encoder creates tokens for each frame. Concatenated memory supports autoregressive decoding, followed by step-synchronous ensemble fusion.

CONTRIBUTION

My part in the work.

This case study describes the project system. A precise breakdown of my individual contribution will be added separately.

OUTCOME

What came out of it.

The repository reports 82.03% exact recognition on a released-label test set of 3,000 tracks.

CONTEXT & LIMITATIONS

This is a post-competition experiment, not an official competition placement. Scorer and label equivalence could not be fully verified. Small gaps to leaderboard systems fall within sampling noise. Code is currently private.
