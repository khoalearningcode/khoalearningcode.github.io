Workflows for AI

PROJECT TYPE

Personal documentation

A collection of reusable protocols with distinct purposes and evidence standards.

PURPOSE

Make the process explicit.

The repository organizes guidance for academic research, challenge participation and coding-agent execution so that the appropriate workflow can be selected for each kind of work.

CONTENTS

Three connected parts.

Research materials include a canonical academic research framework and quick reference. Challenge materials cover competition workflows. The Agent section provides an execution and evidence protocol alongside a repository instruction template.

CURRENT SCOPE

The repository is private. This overview describes its README and document organization; it is not a claim of measured productivity gains. The snapshot does not include a standalone Production workflow.
