# Cao Lê Minh Khoa — Portfolio

Static portfolio for GitHub Pages. Edit `index.html`, case studies in `projects/`, and shared styles in `assets/style.css`. No build step or package installation is required.

Local preview: `python3 -m http.server 4173` from this directory.

Content is based on the supplied CV and project README files. MonoLaDN acceptance and author order are verified against https://accv2026.org/accepted-papers/. Research illustrations are conceptual, not experimental outputs. Private research repositories remain private.

## Site structure

- `index.html`: overview, career preview and three work-channel entry points.
- `career.html`: professional timeline with a separate education and milestones column.
- `channels/`: AI Systems, Multimodal Reasoning, Vision & Efficient Inference.
- `projects/`: individual case studies linked to their parent channel.
- Shared navigation: About / Career / Work / Contact.
